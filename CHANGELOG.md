# CHANGELOG.md

All notable changes to NEURONET are documented in this file.

This project follows [Semantic Versioning](https://semver.org/).

- **MAJOR** — incompatible architecture or constitutional shifts
- **MINOR** — additive engineering capabilities on the roadmap
- **PATCH** — fixes, docs, and non-breaking foundation improvements

Research hypothesis status changes are tracked in `HYPOTHESES.md` and do not by
themselves constitute a software release.

---

## [0.0.0] — Repository Foundation

### Added

- Project constitution (`PHILOSOPHY.md`)
- System architecture overview (`ARCHITECTURE.md`)
- Separated engineering roadmap (`ENGINEERING_ROADMAP.md`)
- Separated research roadmap (`RESEARCH_ROADMAP.md`)
- Scientific hypothesis tracker with initial hypothesis set (`HYPOTHESES.md`)
- Contributor guide (`CONTRIBUTING.md`)
- AI agent guide (`CLAUDE.md`)
- Backend Cargo workspace scaffold (`backend/`)
- Frontend Mission Control folder preparation (`frontend/`)
- Shared contracts preparation (`shared/`)
- Research documentation tree (`docs/`)
- GitHub Actions foundation workflow (`.github/workflows/ci.yml`)
- Repository metadata (`LICENSE`, `.gitignore`, `rust-toolchain.toml`)

### Notes

No Digital Cell runtime, Mission Control UI, or organism application logic is
included in 0.0.0 by design.

Prior experimental trees (including an earlier Digital Cell prototype) were
preserved before this foundation reset at:

- branch `archive/pre-restart`
- tag `pre-restart`

Git history was not deleted.

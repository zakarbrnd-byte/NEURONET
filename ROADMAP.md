# ROADMAP.md — NEURONET Version Plan

This roadmap is sequential by research necessity, not marketing cadence.
Each version must preserve the Five Foundational Laws in `PHILOSOPHY.md`.

---

## Near-Term Versions

### 0.0 — Repository Foundation (current)

Establish the permanent research repository:

- constitution documents
- directory architecture
- engineering standards
- Cargo / frontend / shared scaffolding
- CI skeleton

No organism logic yet.

### 0.1 — Digital Cell

Create the first autonomous computational organism.

- One running Digital Cell
- Local energy, memory, messaging, lifecycle
- Persistence and restore
- Architecture ready for millions of identical cells

### 0.15 — Mission Control

Create the permanent browser observatory.

- REST observatory API
- Live Digital Cell telemetry
- Experimenter controls (wake / sleep / tick / inject)
- Modular sidebar designed for lifelong expansion

Mission Control is a microscope, not a brain.

### 0.2 — Living Network

Move from solitary organism to society.

- Multiple cells in one or more hosts
- Neighbor relationships
- Local message exchange between cells
- No central coordinator of thought

### 0.3 — Adaptive Brain

Introduce plasticity without central planning.

- Strengthen / weaken connections
- Create / prune relationships
- Local adaptation rules
- Still no hardcoded cognition

### 0.4 — Observatory

Expand Mission Control into a multi-cell scientific console.

- Network Map
- Node Inspector
- Metrics surfaces
- Time-oriented observation tools

### 0.5 — Experiment Lab

Formalize experimentation.

- Hypothesis-linked experiment runners
- Controlled stimulus protocols
- Reproducible trial records under `docs/experiments/`
- Comparison across runs and populations

### 0.6 — Learning Engine

Local learning dynamics.

- Reinforcement of useful memories
- Forgetting under pressure or decay
- Confidence dynamics
- Energy-aware learning costs

Learning remains inside cells. It is never a global trainer.

### 0.7 — Emergent Concepts

Seek higher-order structure.

- Repeated associations forming stable patterns
- Concept-like clusters arising from interaction
- Measurement methods for emergent organization
- Aggressive falsification of false positives

### 1.0 — Cognitive Organism

A society-level milestone, not a product launch.

Criteria (aspirational and evidence-based):

- persistent multi-cell organism
- adaptive topology
- measurable emergent organization
- no central brain
- reproducible experiments supporting major hypotheses

1.0 means “the research organism is real,” not “the AGI arrived.”

---

## Long-Term Versions

### 1.x — Multi-Host Life

- Cells across processes and machines
- Locality-preserving networking
- Failure domains and recovery

### 2.x — Evolutionary Substrate

- Population-level variation
- Selection pressures
- Open-ended morphological/behavioral change under local rules

### 3.x — Embodied Environments

- Richer environments and sensors
- Task worlds that reward adaptation without scripting policy networks as minds

### 4.x — Comparative Cognition Studies

- Benchmarks against biological metaphors carefully
- Cross-lab reproducible suites
- Public research datasets from Mission Control captures

### Beyond

If NEURONET ever approaches something like cognition, the roadmap must slow down
and become more scientific, not more theatrical.

The constitution outlives every version number.

---

## Version Discipline

1. Do not skip foundational constraints to chase demos.
2. Every version names what becomes possible **locally**.
3. Mission Control modules activate; they do not rewrite the shell.
4. Hypotheses precede slogans.
5. If a feature requires a central brain, it does not ship.

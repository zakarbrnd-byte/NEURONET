# backend/memory

Local memory owned exclusively by cells.

## Intended contents (future)

- Memory entry model (identity, timestamp, payload, confidence)
- Per-cell memory store
- Seams for learning, forgetting, reinforcement, and pruning

## Rules

- No shared/global memory database of cognition
- Persistence may snapshot local memory; it does not centralize thought
- Forgetting is a first-class future capability

# frontend

Mission Control — the permanent browser observatory for NEURONET.

## Purpose

Provide a scientific operating console for observing, debugging, testing, and
experimenting with artificial organisms.

This is not a chatbot UI.

## Layout

| Path | Role |
|------|------|
| `src/` | Application entry and wiring |
| `components/` | Reusable UI units |
| `layouts/` | Stable shell chrome |
| `pages/` | Module/page surfaces |
| `services/` | API / transport clients |
| `hooks/` | Live organism state hooks |
| `types/` | Frontend-local types |
| `assets/` | Static visual assets |

## Status

Foundation preparation only. Mission Control UI is not implemented in v0.0.0.

## Planned stack

React · TypeScript · Vite

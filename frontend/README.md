# Frontend

Mission Control — the permanent browser observatory for NEURONET.

## Purpose

Provide a scientific operating console for observing, debugging, testing, and
experimenting with the artificial organism.

This is not a chatbot UI. It is an Artificial Life observatory.

## Layout

| Path | Role |
|------|------|
| `src/components/` | Reusable UI units |
| `src/pages/` | Route-level observatory views |
| `src/layouts/` | Shell layouts (top bar, sidebar, workspace) |
| `src/services/` | API / transport clients |
| `src/hooks/` | React hooks for live organism state |
| `src/types/` | Frontend-local types (prefer `shared/` for contracts) |
| `src/assets/` | Static visual assets |

## Status

Foundation preparation only. Mission Control UI is not implemented yet.

## Planned stack

- React
- TypeScript
- Vite

**Status:** Implemented for observation · Conclusion pending validation  
**Version marker:** Structural Plasticity Foundations · Version 0.6C

---

## Hypothesis

If the tissue tracks directed pair coactivation and morphology reach deterministically, Mission Control can observe **where future structural growth or pruning could occur** without creating or deleting synapses.

---

## Exact structural rules

### Coactivation (not STDP)

Directed pair A → B receives coactivation evidence when:

1. A and B both fire on the **same tick**, or
2. A fired on the **previous tick** and B fires on the **current tick**.

Evidence is discrete and tick-based. Wall-clock time is never used. This is **not** STDP.

Pair history is bounded (score capped; list truncated to 64 pairs by recent score).

### Distance and reach

- Positions and morphology (`axonLength`, `dendriteRadius`) use the same **normalized** tissue space as backend positions (not SVG pixels).
- Distance = normalized Euclidean distance between source and target.
- Structural reach = `source.axonLength + target.dendriteRadius`.
- A pair may become a candidate only when it is not a self-connection, no directed synapse already exists, distance ≤ configured max, reach is sufficient, and coactivation score ≥ threshold.

### Growth candidates

Statuses: `observing` · `eligible` · `maturing` · `blocked`  
Readiness ∈ [0, 1] derived from coactivation and compatibility — **not** from elapsed time alone.

Eligible candidates accumulate consecutive evaluations above threshold; after `candidateMaturationTicks` they become `maturing`. If evidence falls below threshold, maturation resets and status returns to `observing` or `blocked`.

**No synapse is created in 0.6C.**

### Pruning risk

Every existing synapse is classified: `stable` · `monitoring` · `atRisk` · `protected`.  
Risk ∈ [0, 1] from low weight, low health, prolonged inactivity, and low stability. Young synapses stay `protected` for a grace period.

**No synapse is deleted in 0.6C.**

### Tick order

1. Neuron firing  
2. Deliver propagations  
3. Electrical recovery (within neuron step)  
4. Synaptic plasticity (Hebbian / idle decay)  
5. Pair coactivation history  
6. On configured intervals: evaluate candidates + pruning risk  
7. Emit structured events  
8. Return snapshot + step trace

## Growth-candidate criteria

| Required | Rule |
| --- | --- |
| Directed | A→B ≠ B→A |
| No self | source ≠ target |
| No duplicate | existing directed synapse blocks candidacy |
| Distance | ≤ `max_candidate_distance` |
| Reach | distance ≤ axon + dendrite reach |
| Evidence | recent coactivation ≥ `minimum_coactivation_score` |
| Type | proposed synapse type = source cell type |

---

## Pruning-risk criteria

| Cue | Effect |
| --- | --- |
| Age < grace | `protected`, risk 0 |
| Weight < threshold | accumulate `low_weight` ticks |
| Health < threshold | accumulate `low_health` ticks |
| Inactivity ≥ threshold | `prolonged_inactivity` |
| Risk ≥ 0.55 | `atRisk` |
| Risk ≥ 0.25 or reasons present | `monitoring` |
| Otherwise | `stable` |

---

## Limitations

- Educational developmental model — not biological growth or pruning.
- No axon geometry animation; no neuron birth/death; no DNA mutation.
- Pair coactivation is a coarse discrete approximation.
- Structural evaluation is interval-based and intentionally slow.

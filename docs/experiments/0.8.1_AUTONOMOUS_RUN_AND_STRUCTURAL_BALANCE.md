# Experiment 0.8.1 — Autonomous Run and Structural Balance

Stabilization patch for Version 0.8. Not a new scientific milestone.

## Problems addressed

1. **Automatic Pause on quiet tissue** — Mission Control stopped Run when no neuron
   was depolarized/fired and no propagation was pending, and also silently stopped
   after `MAX_AUTO_STEPS = 12`.
2. **Birth impossible under Balanced** — growth candidates appeared, but readiness
   stayed below the 0.90 creation threshold while maturation reset on single quiet
   evaluations; unprotected synapses could prune before any birth.

## Root causes (pre-fix)

| Symptom | Cause |
| --- | --- |
| Run pauses on quiet ticks | `networkIsQuiet()` gate inside `runSequenceLoop()` |
| Run stops after ~12 steps | `MAX_AUTO_STEPS = 12` hard ceiling |
| Candidates never become synapses | `creation_readiness_threshold = 0.90` with max readiness ≈ 0.55; maturation wiped by one quiet eval; Pattern B did not reliably build in-reach `NEURON-002 → NEURON-001` coactivation |

## Fixes

### Continuous Run

- Removed activity-based auto-pause and the silent 12-step stop.
- Modes: **Continuous** (until user Pause) and **Observation Run** (default 100 ticks).
- Pause reasons: `None` · `User paused` · `Observation limit reached` · `Backend unavailable` · `Reset`.
- One awaited backend step at a time; AbortController cancels on unmount/reset/pause.
- Empty / quiet `StepTrace` values do not pause.

### Structural balance (Balanced preset)

| Parameter | 0.8 | 0.8.1 |
| --- | --- | --- |
| `creation_readiness_threshold` | 0.90 | **0.65** |
| `minimum_coactivation_score` | 2.0 | **1.0** |
| `candidate_maturation_ticks` | 3 | **2** |
| `evaluation_interval_ticks` | 5 | **4** |
| `pruning_grace_ticks` | 10 | **48** |
| `pruning_inactivity_ticks` | (shorter) | **28** |
| `pruning_commit_risk_threshold` | (lower) | **0.78** |
| Maturation hysteresis | reset on one quiet eval | exit only after 2 evals below 0.75 coactivation |
| Pair score decay | ×0.85 after 5 idle ticks | ×0.92 after 8 idle ticks |
| Pattern B step 2 | weak / non-coactivating | RECEPTOR-A **+16 mV** at offset 2 (builds `002→001`) |
| Pattern A / B intervals (Balanced) | 40 / 55 | **16 / 18** |

Evidence-based birth rules are unchanged: no self-links, no duplicates, structural reach,
eligibility, maturation, readiness threshold, topology capacity.

## Manual public acceptance

1. Reset → Balanced → Environment, Background, Pattern A, Pattern B on.
2. Continuous Run — confirm quiet ticks do not pause.
3. Confirm scheduled sensory events, candidate readiness changes, maturation, and a
   `synapse_created` event within the documented window.
4. Confirm the new synapse appears; tissue does not collapse from early pruning.
5. Pause → pause reason **User paused**.
6. Reset and repeat → deterministic repetition.

# Experiment 0.7 — Developmental Neural Tissue

## Hypothesis

A small artificial tissue can visibly develop over simulation time through a
deterministic lifecycle — progenitor birth → maturation → differentiation →
migration → settlement — without random motion, frontend-owned biology, or
claims of embryological accuracy.

## Lifecycle definition

| State | Behavior |
| --- | --- |
| Quiescent | Reserved; no move, no fire |
| Maturing | Age increases; no fire; no synapses |
| Differentiating | Type + target assigned; no fire |
| Migrating | Position advances along backend path; no fire; no synapses |
| Settling | Fixed at target; brief stabilization; not electrically active |
| Settled | Normal neuron; position fixed; eligible next tick |

Default births begin in **Maturing**. Identity is permanent from birth
(`NEURON-006` …) with lifecycle on the same object.

## Birth rule

A progenitor appears only when all hold:

- development enabled
- total cells < `maximum_total_neurons` (8)
- concurrent developing cells < limit (1)
- tick ≥ first birth tick (30) or ≥ last birth + interval (35)
- deterministic schedule (no randomness)

## Differentiation rule

Choose excitatory vs inhibitory to move the settled population toward
`target_excitatory_ratio` (0.75). Stable ID ordering breaks ties among cells
differentiating in the same evaluation. Settled type never changes later.

## Target-selection rule

1. Deterministic lattice inside settlement zones
2. Reject candidates closer than `MIN_SOMA_SPACING` to occupied/reserved sites
3. Score by spacing and local density
4. Equal scores resolve in stable (y, x) order

## Migration rule

Backend path: start → optional waypoint → target. Progress advances only on
simulation ticks. Step size capped; final position snaps to target without
overshoot. Reason codes: `target_attraction`, `waypoint_progress`,
`target_reached`, `soma_exclusion`, `tissue_boundary`.

## Settlement semantics

On settlement tick X:

- lifecycle → Settled
- soma fixed forever
- `electrically_eligible_from_tick = X + 1`
- `structurally_eligible_from_tick = X + 1`

No retroactive firing or synapse formation on tick X.

## Eligibility semantics

Developing / Settling / not-yet-eligible Settled cells:

- cannot fire
- cannot be electrode-stimulated (API validation error)
- cannot propagate meaningfully as mature neurons
- cannot own active synapses or appear in growth candidates

## Morphology development

Backend exposes `soma_radius`, `dendrite_radius`, `axon_length`,
`morphology_progress` by lifecycle phase. Frontend does not invent branch growth.

## Expected observations

1. Reset → five settled neurons
2. Run to tick 30 → one progenitor in Simplified Progenitor Zone
3. Maturation → differentiation (inhibitory under default E/I ratio) → migration
4. Pause stops further migration
5. Settlement → fixed position; eligible next tick
6. Population 6/8; later births up to 8
7. Reset restores five cells and ID counters; identical sequences reproduce history

## Test protocol

Backend unit/integration tests cover birth bounds, eligibility, determinism,
migration, reset, and event bounds. Frontend tests cover marker, zone rendering,
inspectors, timeline categories, and pause behavior.

## Results

Recorded in CI / local `cargo test` + `vitest` for Version 0.7.

## Limitations

- Progenitor behavior is simplified (not stem-cell biology)
- Differentiation is rule-based, not genetic
- Migration is target-directed and deterministic
- Morphology is abstract
- No cell division, chemical gradients, glia, apoptosis, vasculature
- No biological scale or cognition claimed

## Conclusion

Version 0.7 demonstrates observable, backend-owned tissue development at demo
scale (5→8 neurons) while preserving electrical and structural systems from
0.6A–0.6D.

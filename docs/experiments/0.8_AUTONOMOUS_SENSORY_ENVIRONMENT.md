# Experiment 0.8 — Autonomous Sensory Environment

## Hypothesis

A deterministic virtual environment can supply ongoing, observable sensory input
through dedicated receptor channels so ordinary tissue activity no longer
depends on repetitive manual electrode stimulation — without claiming
perception, meaning, or cognition.

## Environment model

Backend-owned `SensoryEnvironment` with:

- deterministic seed `20260801`
- presets: Quiet / Balanced (default) / Active
- background pulse schedule
- recurring PATTERN-A and PATTERN-B
- bounded event history

Environment age advances only on network ticks.

## Receptor model

Abstract channels (not biological receptors):

| ID | Type | Role |
| --- | --- | --- |
| RECEPTOR-BG | background | Weak baseline pulse |
| RECEPTOR-A | touch_a | Pattern A primary |
| RECEPTOR-B | touch_b | Pattern B primary / A neighbor |

## Sensory connections (Option A)

Fixed developmental interfaces to initial settled neurons only:

- BG → NEURON-001
- A → NEURON-001, NEURON-002
- B → NEURON-002, NEURON-003

Newly settled neurons do not auto-wire to receptors. Sensory connections are
not neural synapses and are not pruned by 0.6D structural rules.

## Event schedule (Balanced)

- Background every 8 ticks, +2 mV via RECEPTOR-BG
- PATTERN-A first at tick 16, repeat every 24 ticks
- PATTERN-B first at tick 28, repeat every 36 ticks

### PATTERN-A steps

1. offset 0: RECEPTOR-A +16 mV (enough to cross threshold on NEURON-001)  
2. offset 1: RECEPTOR-B +8 mV  

### PATTERN-B steps

1. offset 0: RECEPTOR-B +16 mV (enough to cross threshold on NEURON-002)  
2. offset 2: RECEPTOR-A +6 mV  

Delivery uses connection weights scaled by magnitude / 12 mV for touch channels.

## Tick semantics

1. Generate scheduled environment events  
2. Activate receptors  
3. Deliver receptor input to eligible settled neurons  
4. Neuron firing decisions  
5. Synaptic propagation  
6. Recovery  
7. Synaptic plasticity  
8. Coactivation update  
9. Structural evaluation and commit  
10. Developmental lifecycle and migration  
11. Emit structured events  
12. Return snapshot and trace  

Receptor input delivered in Tick X may contribute to firing in Tick X.

## Determinism strategy

Prefer fixed schedules and pattern tables. Identical reset + seed + tick
sequence reproduces event IDs (`ENV-0001`…), deliveries, neural activity, and
topology outcomes.

## Expected neural effects

- Weak background keeps tissue from total silence without saturating weights
- Pattern A/B produce repeatable receptor → neuron input sequences
- Repeated experience can drive Hebbian change and growth-candidate evidence
- New synapses may form via existing 0.6D rules when evidence matures

## Plasticity observation protocol

1. Reset, Run with Balanced preset  
2. Observe PATTERN-A repetitions  
3. Inspect synapse weight history on pathway NEURON-001 → NEURON-002  
4. Note Hebbian strengthen / idle weaken events in timeline  

## Structural-growth observation protocol

1. Continue Run through multiple pattern cycles  
2. Watch growth candidates involving sensory-driven neurons  
3. If a candidate matures under 0.6D rules, observe `synapse_created`  
4. Do not force birth by weakening scientific limits  

## Results

Recorded via backend/frontend tests and public deployment verification for 0.8.

## Limitations

- Receptors are abstract; events are simulated  
- Background activity is an approximation  
- Patterns are externally scheduled (not memory replay)  
- Tissue does not recognize or understand patterns  
- No real-world sensors, reward, perception, goals, or cognition  

## Conclusion

Version 0.8 establishes Environment → Sensory Event → Receptor → Network as
the autonomous input path while preserving laboratory electrode stimulation as
an explicit, separately labeled tool.
